# شواهد بررسی محلی ورک‌فلو

تاریخ: ۲۰۲۶-۱۰-۱۷. منبع: export ارسالی `promty.json`. این نتایج آزمون n8n یا مدل نیستند؛ بازآفرینی منطق مشخص در JavaScript/JSON هستند.

## روش

فایل با Python JSON خوانده شد. تمام پنج مقدار `parameters.text` عیناً به Markdown منتقل شدند؛ SHA-256 منبع و متن هر نود در فایل آرشیو آن ثبت شده است. مسیر خصوصی وب‌هوک و ارجاع credentialها در snapshot تنظیمات ثبت نشده‌اند.

تطابق متن هر پنج فایل آرشیو با مقدار اصلی export و hash آن‌ها بررسی و تأیید شد. فاصله‌ها و خطوط متن اصلی، شامل فاصلهٔ انتهای خط در Design، عمداً حفظ شده‌اند. پیوندهای محلی مستندات و قالب فایل‌های تولیدشده نیز بررسی شدند.

کد اصلی `Code in JavaScript1` پس از خواندن، در Node.js با `vm.runInNewContext` و `$input.first().json` ساختگی، با محدودیت اجرای یک ثانیه اجرا شد. نودهای مدل و وب‌هوک اجرا نشدند. دو عبارت خواندن output مسیریاب روی شیء و رشته بررسی شدند. بخش EXPECTED JSON SCHEMA نود Design بدون تغییر با JSON.parse خوانده شد.

## نتایج هفت بازآفرینی

| نمونه | انتظار از قرارداد سالم | مشاهده در نسخهٔ دریافتی |
|---|---|---|
| `output` رشتهٔ JSON معتبر با body شامل بلوک کد Markdown | حفظ عین body | parse انجام شد ولی حصار کد حذف شد |
| رکورد ساختاریافتهٔ مستقیم، بدون wrapper | خواندن یا رد صریح طبق قرارداد | خطای JSON؛ Code فقط output/text می‌خواند |
| `output` شامل فقط title | رد فقدان body و fieldsSchema | پذیرفته شد؛ tags خودکار افزوده شد |
| body عددی، tags رشته‌ای، fieldsSchema رشته‌ای | رد نوع‌های اشتباه | پذیرفته شد |
| قانون general با output شیء | خواندن category | JSON.parse با خطای `[object Object]` متوقف شد |
| قانون design با output رشتهٔ JSON | خواندن category | `$json.output.routing_category` مقدار undefined داد |
| نمونهٔ JSON انتهای پرامت Design | JSON معتبر | خطای control character در رشتهٔ body |

## بررسی‌های ایستای تکمیلی

- `allowedTaxonomies.industries` در پرامت سه متخصص و QA خوانده می‌شود ولی در درخواست سرور وجود ندارد.
- یک expression با شناسهٔ تنها `placeholder_key` در متن QA پیدا شد؛ مقصود متن نمونه است اما delimiter آن با syntax expression یکسان است. اثر runtime اجرا نشده است.
- pinData خالی است؛ هیچ خروجی واقعی مدل برای ارزیابی صحت محتوا وجود ندارد.
- RouterOutputParser فقط به Router متصل است؛ متخصص‌ها و QA parser متصل ندارند.
- ترتیب شاخه‌ها و اتصالات از JSON استخراج شد؛ تصویر با شاخهٔ Design سازگار است.

اندازه‌گیری توکن، هزینه، latency و کیفیت ترجمه انجام نشده است. lint/build محصول برای آرشیو Markdown اجرا نشد؛ فایل‌های اجرایی محصول تغییر نکردند.
