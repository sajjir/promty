# آماده‌سازی وفادار محتوا و بازبینی ادمین

تاریخ: ۲۰۲۶-۱۰-۲۵. مالک سه تصمیم را صریحاً انتخاب کرد: حفظ اصل و نمایش جداگانهٔ پیشنهادها؛ تعداد فیلد متناسب با نیاز و نمایش اصلی/پیشرفته؛ تمرکز محتوای شروع روی اینستاگرام فروشگاهی، تصویر محصول و توضیح محصول.

## وضعیت واقعی

نسخه روی **draft تستِ ورک‌فلوی اصلی `93Uq9lGFxbSJMGoY`** اعمال شد. پارامتر تمام ۱۱ نود و referenceهای Credential با export نهایی دقیقاً تطبیق دارند؛ timeout=30 محفوظ است. System/User کامل در [current.md](../../06-fast-editor/current.md) هستند. snapshotهای پیشین بازنویسی نشدند. نسخهٔ داخل تب قدیمی `gaaunEOXwrtDtqqS` کپی تست سابق است و در این مرحله ارتقا نیافت.

Publish کلیک نشده است؛ Prepare Input همچنان اجرای غیرtest را رد می‌کند. برای هر درخواست آزمایشی Listen لازم است. active=true قبلی در export به معنی انتشار این draft نیست. نسخهٔ سایت Commit/Push/Deploy نشده است؛ این گزارش، تأیید آماده بودن Production نیست.

## رفتار جدید

- متن خام کامل محفوظ است. هر فیلد عبارت دقیق جایگزین‌شده و پیش‌فرض زبان اصلی/فارسی دارد. کنترل کد، متن زبان اصلی را با بازگرداندن عبارت‌ها دقیقاً با منبع مقایسه می‌کند؛ حذف یا بازنویسی پنهان رد می‌شود. این کنترل، اثبات کیفیت ترجمه یا سازگاری همهٔ گزینه‌ها نیست.
- سقف چهار فیلد حذف شد. کلیدهای ورودی موجود خارج از کد استخراج و به مدل داده می‌شوند؛ schema حداقل تعداد لازم را می‌خواهد. قیود ثابت فیلد نمی‌شوند. صفر فیلد برای متن واقعاً ثابت، موفقیت معتبر است.
- خلاصهٔ قیود ثابت، پیشنهادهای جدا و دلیل/عبارت شاهد تصویر ورودی در editorial ذخیره می‌شوند. پیشنهادها خودکار وارد متن نمی‌شوند. توکن‌های سادهٔ منبع خارج از code fence ورودی احتمالی شمرده می‌شوند؛ literalهای کد باید درست محصور شوند و متن مبهم نیازمند بازبینی است.
- تحلیل ابتدا پیشنهاد نشان می‌دهد؛ اعمال و بازگردانی جداست. شکست تحلیل ویرایش قبلی را پاک نمی‌کند. پیش‌نمایش اصلی و فارسی برای صفر یا چند فیلد وجود دارد. JSON در بخش پیشرفته است.
- محتوای تازه پیش‌نویس شروع می‌شود؛ برای انتشارِ محتوای تحلیل‌شده تأیید روشن بازبینی لازم است و API نیز needsReview=true را با 422 رد می‌کند. این تأیید نشان اجرای آزموده‌شدهٔ ابزار نمی‌سازد.
- ورودی‌های اصلی و تنظیمات بیشتر تفکیک می‌شوند؛ پیش‌فرض‌ها در فرم و صفحهٔ جزئیات یکسان‌اند. گزینهٔ دلخواه برای انتخاب‌های محدودشده غیرفعال است؛ فیلد اجباری خالی در گروه پیشرفته پنهان نمی‌ماند.
- «نیازمند تصویر ورودی» نزدیک فیلترهای اصلی و روی هر دو قالب کارت قرار دارد. URL، شمارنده و جستجو/دسته/خروجی/صفحه‌بندی هماهنگ‌اند. هنگام فیلتر یا جستجوی فعال قفسه‌های بدون فیلتر پنهان می‌شوند. false قدیمی به معنی تأیید «بی‌نیاز بودن از عکس» معرفی نشده است.

زمان کامل دریافت پاسخ کارتونی در داشبورد **۸٫۷ ثانیه** نمایش داده شد. زمان‌های جدول processingMs درخواست‌اند، نه شمارندهٔ اجرای n8n که می‌تواند انتظار listener را هم حساب کند. این چهار ورودی نهایی موفق بودند؛ تضمین همهٔ ورودی‌ها، همزمانی یا p95 ارائه نمی‌شود.

هر چهار body ثبت‌شده از فرم با متن خام بازسازی و دقیقاً برابر شدند. ترجمهٔ کارتونی، تمام شروط حفظ صحنه/هویت، AVOID، نسبت تصویر و توصیهٔ یک عکس را داشت و hand-drawn را «دست‌کشیده» ترجمه کرد. این تست، اجرای تولید تصویر یا اثبات حفظ هویت توسط ابزار مقصد نیست.

تست‌های بین‌راهی محفوظ‌اند: تابع بسته‌بندی‌شده ابتدا با sandbox n8n سازگار نبود و پاسخ با 422 رد شد؛ تابع مستقیم جایگزین شد. در v006 مدل ورودی‌های کپشن را فیلدگذاری نکرد؛ کنترل برابری متغیرها آن را رد کرد و ورودی‌های موجود به قرارداد افزوده شدند. نسخهٔ نهایی در چهار ورودی بالا موفق شد. یک خطای متادیتای زبان در کپشن دیده شد؛ برنامه اکنون ناسازگاری «منبع بدون حروف فارسی / زبان فارسی» را آشکارا برای اصلاح ادمین هشدار می‌دهد. ادعای QA معنایی کامل نداریم.

## آزمون برنامه و ذخیره‌سازی

TypeScript، Build و ۳۱ آزمون مرتبط موفق بودند؛ بررسی مستقل runtime قرارداد نیز موفق شد. حذف شرط، پیش‌فرض ناسازگار، شش ورودی، تغییر indentation کد، فیلتر ترکیبی، شمارنده، صفحه‌بندی، stream ناقص و خروجی قدیمی پوشش دارند. فایل check-runtime.cjs ابزار محیط توسعهٔ این پروژه است و برای fixture شیت به مسیر محلی گزارش‌های سابق نیاز دارد؛ تست خودبسندهٔ قابل اجرا در هر checkout معرفی نشده است.

یک پیش‌نویس با عنوان شروع‌شونده با `[تست لوکال]` و شناسه `cmvnkwnkq0001tqbjj5ntcszw` در PostgreSQL ایزوله ذخیره شد. isActive=false، پنج فیلد، editorial.needsReview=true، اصل منبع و fidelity محفوظ بودند. بازخوانی API ادمین موفق، درخواست مهمان همان draft برابر 404 و تلاش create/update انتشارِ بازبینی‌نشده برابر 422 بود. محتوای عمومی منتشر نشد.

آزمون مرورگر «business + referenceImage=required» دقیقاً دو نتیجه و دو نشان تصویر داشت؛ قفسه‌های نامرتبط حذف شدند. عنوان فرم پیش از اعمال پیشنهاد حفظ و با Undo بازگردانده شد؛ انتشار بدون تأیید نیز از UI متوقف شد.

## محدوده و قدم رسمی بعدی

مسیر سریع تا ۶۰۰۰ نویسه می‌پذیرد؛ متن بزرگ‌تر با پیام روشن رد می‌شود و پنهانی خلاصه نمی‌شود. مهلت کامل خواندن پاسخ API حداکثر ۳۰ ثانیه است. خطای مدل، شبکه یا پاسخ نامعتبر همچنان ممکن است و به موفقیت کاذب تبدیل نمی‌شود.

برای استفادهٔ دائمی ادمین‌ها، endpoint امن دائمی و انتشار نسخهٔ دقیق سایت هنوز لازم است. تغییرات ثبت‌نشدهٔ قبلی schema/editorial باید در بستهٔ انتشار جدا بررسی شوند؛ هیچ migration یا تغییر سرور برنامه در این مرحله انجام نشد. صفحات سئوی مجموعه‌ها، canonical و sitemap نیز موضوع جدا از آماده‌سازی پرامپت‌اند و اجراشده محسوب نمی‌شوند.

بکاپ پیش از تغییر و export نهایی فقط در مخزن خصوصی خارج Git هستند. قالب Redacted هیچ Credential reference، شناسه شیت یا مسیر واقعی webhook ندارد و قبل از استفاده نیاز به اتصال محیط مقصد دارد. گزارش ماشینی: [validation-and-application.json](validation-and-application.json).

پیش‌نویس آزمایشی از فرم ویرایش دوباره باز شد؛ زبان متن اصلی آن با بازبینی دستی از فارسی به انگلیسی اصلاح و دوباره به‌صورت غیرفعال ذخیره شد. این نمونه نشان می‌دهد پیشنهاد طبقه‌بندی مدل همچنان نیاز به بازبینی دارد.
