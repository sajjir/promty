# اعمال روی ورک‌فلوی اصلی و آزمون از داشبورد

تاریخ: ۲۰۲۶-۱۰-۲۴. مالک صریحاً درخواست ویرایش ورک‌فلوی اصلی برای تست واقعی را داد.

## نتیجه

روی همان شناسهٔ `93Uq9lGFxbSJMGoY` نمودار ۳۴ نودی قبلی با مسیر سریع ۱۱ نودی جایگزین شد. بکاپ کامل قبل از تغییر و export پس از تغییر در مخزن محرمانهٔ خارج Git محفوظ‌اند. پارامتر تک‌تک نودها، referenceهای Credential و همهٔ اتصال‌ها با نامزد دقیقاً تطبیق داده شدند. export نهایی `executionTimeout=30` را تأیید کرد. نام، مسیر و ID وبهوک اصلی حفظ شدند. Gemini/Sheets همان Credentialهای موجود را استفاده می‌کنند؛ مقدار کلیدها استخراج نشد.

این تغییر روی draft تست است؛ Publish کلیک نشده است. active=true در export مربوط به وضعیت قبلی workflow است و به‌تنهایی اعمال draft روی endpoint تولیدی را ثابت نمی‌کند. Prepare Input همچنان اجرای غیر test را رد می‌کند؛ برای استفادهٔ دائمی endpoint امن و طرح انتشار لازم است.

## آزمون واقعی dashboard → API → webhook اصلی → فرم

لوکال با PostgreSQL ایزوله روی loopback راه‌اندازی و حساب آزمایشی ادمین از فرم معمول ورود احراز هویت شد. Analyze URL لوکال با وبهوک اصلی تطبیق داشت؛ مهلت پاسخ لوکال ۳۰ ثانیه ذخیره شد. از فرم `/admin/prompts/new` متن کارتونی کاربر با دکمهٔ چشمه ارسال شد و n8n ورود از Webhook را ثبت کرد.

- پاسخ معتبر وارد فرم شد و اعلان موفقیت/پنل «گزارش بازبینی ایجنت — نیازمند بررسی» نمایش داده شد.
- `processingMs=7429`، `catalogMs=2209`، `modelMs=5220`، یک فراخوانی `gemini-3.5-flash-lite`، ۵۸۶۵ توکن ورودی و ۱۳۱۸ خروجی.
- زمان مشاهدهٔ فرم موفق از لحظهٔ کلیک ۲۱۶۹۲ میلی‌ثانیه بود؛ این کران بالای شامل فاصلهٔ مشاهدهٔ عامل است، نه زمان دقیق شبکه.
- شمارندهٔ کلی n8n برابر ۴۶٫۹۰۵ ثانیه بود و انتظار مسلح بودن listener پیش از درخواست را نیز شامل شد؛ با زمان پردازش واقعی درخواست اشتباه نشود.
- کاربرد `vis-09`، نوع `prompt`، زبان `english`، نیاز به عکس مرجع، کاربردهای مرتبط و دو متن وارد شدند. متن انگلیسی با منبع کامل پس از حذف عنوان PROMPT و نرمال‌سازی whitespace دقیقاً برابر بود. وجود ترجمهٔ کامل، فهرست ممنوعیت‌ها و پنل بازبینی کنترل شد.
- این اجرای واقعی fieldsSchema خالی داشت؛ کنترل شخصی‌سازی تازه‌ای ساخته نشد. قرار نیست برای هر متن تعداد ثابتی فیلد تحمیل شود. آزمون‌های قبلی گزینهٔ رنگ متناقض تولید کرده بودند؛ کیفیت همهٔ گزینه‌ها همچنان نیازمند بازبینی ادمین است.
- فرم باز و پرشده باقی ماند؛ پرامپت ذخیره/منتشر نشد. کد برنامه، Commit/Push، سرور برنامه و migration تغییر نکردند.

## متن دقیق و بازگشت

System/User کامل همان [ایجنت v004-proposed](../../06-fast-editor/v004-proposed.md) است و با متن embedded در export نهایی تطبیق دارد. وضعیت proposed نشان می‌دهد پذیرش و انتشار نهایی انجام نشده؛ شاهد اعمال draft و E2E در همین سند و `application-and-e2e.json` جدا ثبت شده است. نسخهٔ sanitized فقط برای بازسازی است و به ID شیت/Credentialهای مقصد نیاز دارد. فایل محرمانهٔ اصلی نباید وارد Git شود.

برای بازگشت، export کامل `main-before-fast-application.json` در پوشهٔ خصوصی همین مرحله محفوظ است. آن را تنها در همان workflow و با رعایت وضعیت draft/published بازیابی کنید؛ Publish مرحلهٔ جداست.
