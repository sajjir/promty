## اجراهای واقعی

- Gemini 3.8: یک 503 به دلیل high demand؛ یک timeout ۲۴ ثانیه‌ای.
- Flash-Lite بدون schema: ۱۶٫۲۹۹ ثانیه ولی fields نامعتبر؛ سپس ۱۲٫۳۲۲ ثانیه با ساختار معتبر ولی حذف بندهای منبع و گزینهٔ متناقض. هیچ‌کدام پذیرفته نشدند.
- پیام سخت‌گیرانه‌تر: یک 503؛ سپس ۱۶٫۸۳۷ ثانیه با پوشش منبع اما JSON نامعتبر و نام ابزار بی‌منبع؛ رد شد.
