# آماده‌سازی پرامپت با اولویت کیفیت — ۲۰۲۶-۱۰-۲۶

وضعیت: **v010 proposed؛ آمادهٔ آزمون مستقل، اعمال و منتشر نشده**. درخواست مالک: حفظ کیفیت، بازگشت متغیرهای مفید، حداکثر هدف ۴۵ ثانیه. مالک فعلاً امکان اتصال مجدد Google Sheets را ندارد و آماده‌سازی مستقل را انتخاب کرده است.

## علت اصلاح

سیاست قبلی امکان خروجی بدون فیلد را بدون گزارش تصمیم روشن می‌داد؛ نمونهٔ کارتونی در آزمون قبلی واقعاً صفر فیلد داشت. وجود قیود ثابت نباید مانع شناسایی کنترل محدود و مفید شود. در اتصال سایت هم تطابق متغیرهای هر دو زبان با فرم و حفظ ورودی‌های متن خام باید مستقل کنترل شود. محدودیت سخت ۳۰ ثانیهٔ Analyze نیز با درخواست تازه ناسازگار بود.

## تغییرها

- پیام تازه، کامل و بدون الحاق دستورهای متناقض: [System](system-message.txt)، [User expression](user-message.txt)، [آرشیو جاری](../../06-fast-editor/current.md).
- یک فراخوانی مدل و همان مدل تنظیم‌شدهٔ export؛ بررسی فعال ابعاد قابل شخصی‌سازی بدون سقف یا سهمیهٔ مصنوعی. پیش‌نیاز تصویر، هویت، ترکیب‌بندی و ممنوعیت‌ها ثابت می‌مانند.
- گزارش `editorial.personalizationReview`: هر فیلد شاهد و دلیل دارد؛ خروجی واقعاً ثابت نیز دلیل مشخص دارد. این گزارش تضمین کیفیت معنایی یا مجوز انتشار نیست.
- حفظ متن اصلی با بازسازی دقیق از عبارت‌های جایگزین‌شده؛ ترجمهٔ کامل، تطابق کلیدها/تعداد متغیرها و کنترل ساختاری مستقل. پیشنهادهای بهبود جدا می‌مانند.
- بودجهٔ داخلی ۴۳ ثانیه، درخواست مدل حداکثر ۳۹ ثانیه، رد پاسخ کامل‌نشده یا دیررس از ۴۴ ثانیه و سقف Analyze سایت ۴۵ ثانیه. تنظیم thinking به MEDIUM و سقف خروجی ۱۰۰۰۰ توکن نامزد آزمون است؛ زمان و هزینهٔ واقعی هنوز سنجیده نشده‌اند. طول ورودی فعلی حداکثر ۶۰۰۰ نویسه است.
- سایت گزارش تصمیم را پیش از اعمال نشان می‌دهد؛ خروجی قدیمی بدون فیلد و بدون دلیل را برای بازبینی علامت می‌زند و پاسخ دارای ورودیِ بدون فیلد یا ترجمهٔ ناسازگار را نمی‌پذیرد.

## فایل Import و مرز اتصال

[قالب JSON با حذف مشخصات محیط](Promty-Quality-Redacted-Template.json) برای import در یک workflow خالی و غیرفعال است. credentialها، شناسهٔ سند شیت و مسیر خصوصی webhook حذف شده‌اند؛ پیش از اجرا، credential موجود، سند واقعی، برگه‌های واژگان/قواعد و مسیر تست باید تنظیم شوند. این بسته همچنان guard تست دارد و اجرای production را رد می‌کند؛ آمادهٔ Publish دائمی نیست. Import را روی نسخهٔ اصلی جایگزین نکنید و برای این آزمون workflow اصلی را فعال نکنید.

نسخهٔ خصوصی با اتصالات موجود و export پشتیبان در پوشهٔ خصوصی لوکال بیرون Git نگهداری می‌شوند. خود این بسته credential را اصلاح نمی‌کند. برای تست دستی START را انتخاب کنید؛ برای تست داشبورد، Listen for test event را در همین نسخهٔ تست فعال کنید و تنها URL تست همین نسخه را در تنظیمات لوکال قرار دهید. URL تولیدی یا تنظیم سایت اصلی در این مرحله تغییر نمی‌کند.

- چهار آزمون متمرکز: دو کنترل محدود کارتونی و بازسازی متن؛ خروجی ثابت معتبر و دلیل جعلی؛ حفظ ورودی‌های موجود/کد ثابت/بیش از چهار فیلد؛ پذیرش پاسخ مصنوعی ۳۲ثانیه‌ای و رد پاسخ ناقص یا ۴۴ثانیه‌ای. این ساعت‌های تزریقی، زمان واقعی مدل نیستند.

نسخهٔ لوکال با build جدید راه‌اندازی شد؛ صفحهٔ اصلی و API تنظیمات پاسخ ۲۰۰ دادند و زمان انتظار تحلیل روی ۴۵ ثانیه ذخیره شد. آدرس webhook، داده‌های محتوا و تنظیمات سایت اصلی تغییر نکردند.

## پذیرش پس از اتصال مجدد

چهار ورودی واقعی کپشن اینستاگرام، تصویر محصول، توضیح محصول و عکس کارتونی را هرکدام حداقل سه بار از داشبورد تست کنید. پاسخ کامل باید حداکثر ۴۵ ثانیه برسد؛ هیچ قطع خروجی، حذف بند منبع یا ناهماهنگی فرم مجاز نیست. ادمین کامل بودن ترجمه، مفید بودن کنترل‌ها، صحت همهٔ گزینه‌ها و طبقه‌بندی را بررسی کند. موارد واقعاً ثابت نباید فیلد ساختگی بگیرند. کیفیت معنایی با پاس شدن validator اثبات نمی‌شود. فقط پس از این آزمون‌ها می‌توان دربارهٔ اعمال نسخهٔ اصلی تصمیم گرفت.
