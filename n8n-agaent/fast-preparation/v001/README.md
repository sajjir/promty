# مسیر سریع آماده‌سازی — v001 پیشنهادی

تاریخ: ۲۰۲۶-۱۰-۲۴. درخواست مالک: نتیجهٔ کامل و معتبر در پرامتی در حداکثر ۳۰ ثانیه. وضعیت: فایل نامزد ساخته و با fixture بررسی شده؛ هنوز روی ورک‌فلوی زنده اعمال نشده و هیچ زمان واقعی جدیدی اندازه‌گیری نشده است.

## تغییر معماری

یک فراخوانی OpenRouter با همان مدل موجود در snapshot (`deepseek/deepseek-v4.1-flash`) به جای Router + تخصص + بازنویسی QA و حلقهٔ tool. دو خواندن شیت (واژگان و قواعد)، بدون خواندن صف پیشنهادها یا بازخوانی کاتالوگ در مسیر پاسخ. همهٔ ۱۷۰ کاربرد فعال fixture به صورت فهرست فشرده در ورودی حاضر می‌مانند؛ حدس top-k جایگزین فهرست کامل نشده است.

System از ۱۴٬۰۹۸ نویسهٔ Design و ۱۸٬۲۷۶ نویسهٔ QA در snapshot قبلی به یک پیام ۵٬۰۴۰ نویسه‌ای رسیده است؛ این شمارش نویسه است، نه توکن یا سنجش سرعت واقعی. reasoning در درخواست خاموش است، نه فقط مخفی؛ retry خودکار و auto-repair مدل نداریم. انتخاب مدل موجود حفظ شده؛ سرعت آن هنوز باید با حساب واقعی سنجیده شود.

## کیفیت و مرزها

خروجی همان ۱۸ کلید، دو متن، فیلدهای معنادار و طبقه‌بندی است. اعتبارسنجی ساختار، کاتالوگ و برابری متغیرها با کد حفظ شده است. مدل دوم دیگر بازبینی معنایی نمی‌کند؛ خروجی همیشه نیازمند بررسی نهایی ادمین و به عنوان پیش‌نویس است. هیچ ادعای آزمون ابزار تولید نمی‌شود.

نوشتن خودکار در صف شیت روی مسیر سریع وجود ندارد. نبود کاربرد مناسب با needsReview گزارش می‌شود؛ ثبت موفق جعلی یا فعال‌سازی کاتالوگ نداریم. writer قدیمی و همهٔ snapshotهای گذشته محفوظ‌اند؛ این فایل آن‌ها را حذف یا تغییر نداده است. نگهداری/گسترش کاتالوگ باید جدا از زمان پاسخ ادمین طراحی شود و هنگام اجرای چند ادمین، کنترل همزمانی واقعی داشته باشد.

## فایل‌ها و اعمال

- system-message.txt و user-message.txt متن کامل قابل کپی هستند؛ `=` ابتدای User متعلق به expression export است.
- contract-helpers.js و fast-helpers.js کنترل‌های مستقل از مدل را دارند؛ بدون شبکه و secrets.
- Promty-Fast-Template.json قالب بدون credential، مسیر خصوصی وبهوک و شناسهٔ شیت است؛ بعد از Import باید شیت و credential موجود انتخاب شوند.
- نسخهٔ خصوصی نامزد با ارجاع‌های فعلی credential و شیت، در پوشهٔ خصوصی لوکال n8n-fast-2026-10-24 نگهداری می‌شود. هیچ API key در export نیست.

این نامزد از snapshot ذخیره‌شدهٔ ۲۲ اکتبر ساخته شده است. پیش از اعمال باید export فعلی n8n دوباره خوانده و تغییرات جدید مالک حفظ شوند. workflow منتشر نمی‌شود؛ Prepare Input عمداً اجرای غیر test را رد می‌کند. اتصال رسمی چندادمینی به endpoint تولیدی امن هنوز تکمیل نشده است.

## پذیرش

۹ بررسی محلی پاس شدند؛ validation.json دقیقاً محدوده را می‌گوید. زمان‌های ساختگی fixture اثبات latency مدل نیستند. benchmark.py یک درخواست واقعی به وبهوک تست آماده می‌فرستد و فقط HTTP 200 با رکورد کامل و زمان کمتر از ۳۰ ثانیه را می‌پذیرد. timeout، خروجی بریده، JSON خراب یا رسید اولیه قبول نیست.

مهلت ۳۰ ثانیه به خودی خود تضمین تحویل نتیجه نیست؛ موفقیت نیازمند چند اجرای واقعی با متن کارتونی و نمونه‌های دیگر، کنترل کیفیت فارسی و انگلیسی، و اندازه‌گیری dashboard→API→n8n→form است. نتیجهٔ کوتاه‌شده یا پاسخ cache‌شدهٔ قبلی جای این تست نیست. فعلاً هیچ benchmark زنده اجرا نشده است.
