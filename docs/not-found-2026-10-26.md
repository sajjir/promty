# صفحهٔ ۴۰۴ — ۲۶ اکتبر ۲۰۲۶

درخواست مالک: نمایش چهرهٔ متحرک SVG ارسالی و دقیقاً همان سناریوهای تنظیم‌شده زیر جستجوی هوم‌پیج برای راهنمایی به آرشیو دارای محتوا.

## پیاده‌سازی محلی

- `NotFoundContent` برای نمایش یکسان در HTML سرور و React؛ رنگ سازگار با پوسته و توقف انیمیشن در حالت کاهش حرکت سیستم.
- `QuickChipLinks` مشترک با هوم‌پیج؛ عنوان، ترتیب، آیکن، کاربرد و ابزار از تنظیمات موجود خوانده می‌شوند.
- شمارش مشترک `homepageChipCounts` فقط محتوای منتشرشده را می‌شمارد. سناریوهای خالی یا هنوز دریافت‌نشده لینک فعال ندارند؛ بازگشت به آرشیو همیشه در دسترس است.
- مسیر ناشناخته و محتوای ناموجود/منتشرنشده با HTTP 404 و `noindex, follow` باقی می‌مانند؛ پاسخ 503 سرویس با 404 اشتباه نمی‌شود.
- در پیمایش داخلی، وضعیت SEO فقط برای همان آدرس اعمال می‌شود تا بازگشت به صفحهٔ معتبر مسدود نشود.

## اعتبارسنجی

- TypeScript و Build موفق؛ هشدار قبلی اندازهٔ بستهٔ اصلی همچنان وجود دارد.
- آزمون واحد مسیرهای ناموجود و حریم خصوصی پیش‌نویس، تنظیمات سفارشی و سناریوهای فاقد محتوا؛ آزمون HTTP برای 404 واقعی و لینک/آیکن سناریوی ذخیره‌شده.
- مرورگر: نمایش موبایل 393×852 بدون سرریز افقی؛ کلیک «تبدیل عکس به کارتون» از صفحهٔ 404 به آرشیو با یک نتیجه رسید؛ حساب مدیر همچنان وارد است.
- این مرحله فقط لوکال است؛ انتشار سرور انجام نشده است.
