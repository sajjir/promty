# سئو، سناریوهای هوم‌پیج و کتابخانهٔ رسانه

وضعیت: پیاده‌سازی و کنترل فنی لوکال روی برنچ finaly، بر پایهٔ 5025103؛ Commit/Push/Deploy جدید انجام نشده است. محتوای اصلی همچنان در PostgreSQL لوکال است؛ migration جدیدی برای این مرحله لازم نیست. تنظیمات جدید مانند سایر تنظیمات برندینگ فعلی در db.json پایدار نگهداری می‌شوند و رسانه‌ها فایل‌اند؛ مهاجرت کامل settings به PostgreSQL موضوع جداست.

## مبنای بررسی
ادعاهای گزارش مالک با کد تطبیق داده شد: شمارنده‌ها، فیلتر پیش از صفحه‌بندی و URL از قبل وجود داشتند؛ تقویت شدند. aggregateRating ساختگی قبلاً در نسخهٔ مبنا حذف شده بود؛ این مرحله HowTo عمومی را هم با CreativeWork واقعی جایگزین کرد. وضعیت 404 جزئیات پیش‌تر برای مهمان JSON بود؛ اکنون صفحهٔ HTML با noindex برمی‌گردد.

منابع رسمی بررسی‌شده در ۲۰۲۶-۱۰-۲۵:
- [JavaScript SEO، کد وضعیت، رندر اولیه و canonical](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)
- [لینک‌های قابل خزش](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)
- [سیاست دادهٔ ساختاریافته](https://developers.google.com/search/docs/appearance/structured-data/sd-policies)
- [ناوبری فیلترها](https://developers.google.com/crawling/docs/faceted-navigation)
این پیاده‌سازی تضمین رتبه، ستاره یا ایندکس فوری نیست؛ پذیرش Search Console و Rich Results پس از انتشار جدا بررسی می‌شود.

## سئو و آرشیو
- robots.txt متن واقعی و sitemap.xml XML داینامیک با URL کامل هستند. نقشه فقط صفحات منتشرشده و صفحات کاربرد/ابزار/حوزهٔ دارای محتوای منتشرشده را شامل می‌شود؛ draft و فیلترهای ترکیبی در آن نیستند.
- مسیر ناشناخته، شناسهٔ مفقود، جزئیات منتشرنشده، کاربرد خالی و صفحه‌بندی خارج محدوده 404 واقعی دارند. صفحهٔ HTML 404 دارای noindex و X-Robots-Tag است. دارایی/API ناموجود نیز دیگر index.html با 200 نمی‌گیرد. خطای دسترسی داده به 503 تبدیل می‌شود، نه موفقیت کاذب.
- metaهای ثابت عنوان/description/OG/canonical پیش از درج نسخهٔ یکتا پاک می‌شوند. /prompt/:id به /prompts/:id با 301 منتقل می‌شود. مسیرهای حساب و queryهای جستجو/ترکیب فیلتر noindex هستند؛ صفحهٔ بعدِ آرشیو canonical همان صفحه را دارد. لینک‌های داخلی به دسته‌های تمیز محدودند؛ ترکیبات دلخواه بی‌شمار در sitemap تولید نمی‌شوند.
- HTML اولیه یک بلوک معنایی قابل مشاهده دارد: عنوان، توضیح، متن کامل قالب و نسخهٔ فارسی، راهنمای فیلدها، تصویر نمونهٔ واقعیِ ثبت‌شده، لینک کاربرد و منابع هم‌خانواده. محتوا مخفی نیست و برای همهٔ درخواست‌کنندگان یکسان است؛ با اجرای React همان محتوای برنامه جای آن را می‌گیرد. دادهٔ خام/گزارش editorial ادمین وارد HTML عمومی نمی‌شود.
- BreadcrumbList و CreativeWork از دادهٔ واقعی صفحه ساخته می‌شوند؛ متن/متغیرها/ابزارها و تصویر ثبت‌شده، بدون رأی و امتیاز استنباطی. ورودی HTML و JSON-LD escape می‌شود. تغییر مسیر داخلی React هم head را از همان قرارداد عمومی سرور همگام می‌کند.
- /use-case/:slug در سرور و React فعال است؛ عنوان و H1 اختصاصی و لینک استاندارد دارد. کارت‌ها، منابع مرتبط، قفسه‌ها و صفحه‌بندی از href واقعی استفاده می‌کنند. بارگذاری بیشتر به صفحه‌بندی URLدار قبل/بعد تبدیل شده تا refresh و برگشت صفحه را حفظ کند.
- پیش‌نمایش 5173 با Vite/HMR از همان رندر عمومی API استفاده می‌کند؛ پاسخ status و HTML اولیهٔ آن با سرور هماهنگ است. /sitemap.xml و /robots.txt از API لوکال proxy می‌شوند.

## سناریوها و فیلترها
مسیر ادمین: «برندینگ و ظاهر سایت» ← تب داخلی «هوم‌پیج و سناریوها». شش سناریوی پیشنهادی اولیه و حداکثر هشت مورد؛ فعال‌بودن، عنوان، ترتیب بالا/پایین، کاربرد، ابزار اختیاری و آیکن قابل تنظیم‌اند. این شش مورد ادعای محبوبیت آماری ندارند. ابزار فقط با انتخاب ادمین محدود می‌شود، نه سازگاری حدسی با همهٔ مدل‌ها. SVG از کتابخانه آپلود و با حفظ ظاهر به WebP مستقل تبدیل می‌شود. انتخاب و ویرایش‌ها با دکمهٔ ذخیرهٔ برندینگ اعمال می‌شوند.

چیپ‌ها زیر جستجو با لینک کاربرد و ابزار انتخاب‌شده ظاهر می‌شوند؛ شمارندهٔ آن‌ها از کل دادهٔ منتشرشده و ترکیب دقیق خود سناریو محاسبه می‌شود. مورد صفر غیرفعال است. چندانتخابی‌ها هم گزینهٔ صفر را غیرفعال می‌کنند، ولی انتخابِ صفرِ ازقبل اعمال‌شده برای برداشتن همچنان قابل دسترس است. فیلتر/مرتب‌سازی کل آرشیو همچنان پیش از صفحه‌بندی در سرور انجام می‌شود.

نوار فیلترهای فعال شامل جستجو، انتخاب‌ها و مرتب‌سازی بالای نتایج چسبان است؛ فاصلهٔ آن با ارتفاع واقعی هدر، حتی لوگوی بزرگ، محاسبه می‌شود. حذف تکی و پاک‌سازی همه URL را تغییر می‌دهند. صفحه و sort در URL می‌مانند؛ لینک بازگشت از جزئیات، آخرین آدرس آرشیو همین نشست را بازیابی می‌کند. با فیلتر/جستجو قفسه‌های بدون فیلتر همچنان مخفی‌اند.

## رسانه
- انتخاب‌گر مشترک ادمین با preview، جستجو، انتخاب تکی/چندتایی، آپلود جدید و حذفِ فایل بدون استفاده؛ همهٔ ادمین‌های دارای همان نقش مجاز به کتابخانه دسترسی دارند. نام محتواهای استفاده‌کننده در فهرست کمک به جستجو می‌کند.
- فایل‌های موجود فعلی زیر dl/prompts، dl/brand و dl/library دیده می‌شوند؛ thumbnailهای تولیدشده برای جلوگیری از تکرار پنهان‌اند. نسخه‌های تاریخیِ قبلاً بازنویسی/حذف‌شده ادعای بازیابی ندارند؛ از این پس لوگوها URL یکتای library می‌گیرند و کاور قبلی پیش از جایگزینی آرشیو می‌شود.
- انتخاب از کتابخانه کنار آپلود لوگو/کاور و برای گالری/تصویر نمونه در فرم محتوا وجود دارد؛ برداشتن کاور/عضو گالری از فرم، فایل فیزیکی را حذف نمی‌کند. انتخاب با ذخیرهٔ فرم به محتوا مرتبط می‌شود.
- استفادهٔ مجدد از تصویر قدیمی، کپی مستقل immutable در library می‌سازد؛ انتشار آن به وضعیت پرامپت منبع وابسته نیست. فایل library تا زمانی که در یک محتوای منتشرشده یا تنظیم عمومی فعال استفاده نشود برای مهمان 404 است؛ ادمین preview مجاز دارد. تصاویر پیش‌نویسِ اصلی همچنان خصوصی‌اند.
- استفاده در هر پیش‌نویس/محتوای منتشرشده/تنظیم، از جمله آیکن سناریوی غیرفعال، مانع حذف است (409). حذفِ مجاز فایل را به .private/media-trash منتقل می‌کند؛ بازیابی آن فعلاً توسط اپراتور از فایل خصوصی ممکن است و UI بازیابی ارائه نشده است. بکاپ باید dl و .private را شامل شود.
- JPEG/PNG/WebP/SVG حداکثر۵MB، محدودیت پیکسل/ابعاد و فقط یک فریم. فایل‌ها decode و دوباره encode می‌شوند. SVG دارای script، handler، منبع خارجی، entity/doctype یا import رد می‌شود؛ SVG خام عمومی سرو نمی‌شود. URLهای دلخواه به فایل سیستم ترجمه نمی‌شوند و inventory مسیرهای مجاز را کنترل می‌کند.

## شواهد و حدود تست
TypeScript، بیلد و هر۴۴ آزمون موفق‌اند؛ آزمون‌های اضافه، HTTP واقعی در محیط موقت هستند: MIME صحیح sitemap/robots، draft/ناشناخته404، escaping و canonical یکتا، متن اولیه، صفحه‌بندی بیش از یک صفحه، سناریوی نامعتبر، اشتراک کتابخانه بین دو ادمین، SVG ناامن، حریم فایل استفاده‌نشده، کپی از رسانهٔ draft، انتشار آیکن از طریق تنظیم و منع حذف فایل در حال استفاده.

API لوکال با همان PostgreSQL و کلید نشست پایدار restart شد. HTTP واقعی در5173 تأیید کرد: خانه200 با description/canonical یکتا؛ sitemap200 با application/xml؛ robots200 با text/plain و خطوط واقعی؛ ناشناخته و شناسهٔ مفقود404 HTML/noindex؛ جزئیات یک محتوای منتشرشده دارای متن اصلی در سورس؛ صفحهٔ کاربرد همان محتوا200 با لینک‌های داخلی. رسید در .local-preview/seo-media-local-check.json خارج Git است. آزمایش رسانه‌ها در فضای موقت انجام شد و دادهٔ واقعی لوکال برای تست overwrite نشد.

بازبینی ظاهری/تعاملی دسکتاپ و موبایل با ابزار انجام نشد: CUA همچنان transport closed before response داد. موفقیت بیلد/HTTP جای آن اعلام نمی‌شود. بررسی Search Console/Rich Results و انتشار سرور در این مرحله انجام نشده‌اند. سایت Production همچنان5025103 است.
