# فرایند Project Brain
قواعد اصلی در [AGENTS.md](../AGENTS.md) هستند؛ این سند گردش کار را توضیح می‌دهد.

۱. نوع اقدام، هدف، محدوده و پذیرش را مشخص کن؛ برای کار کوچک کوتاه باشد.
۲. وضعیت Git، کد و اسناد مرتبط را بخوان؛ فرض و شواهد را جدا کن.
۳. برای کار بزرگ برنامه مرحله‌ای با وابستگی، مالک فایل، تست و بازگشت بده.
۴. کارهای محلی مجاز را اجرا و متناسب تست کن. تغییرات کاربر حفظ شوند.
۵. در کار مشترک هر فایل فقط یک مالک ویرایش داشته باشد؛ متخصص بدون هماهنگی فایل دیگری را تغییر ندهد.
۶. نتیجه را با شواهد اجرا، محدودیت و موارد باقی‌مانده گزارش کن؛ Build موفق جای تست رفتار نیست.

Project Brain نقطه اصلی گفتگو است. نقش‌های UI/UX، تحقیق، پیاده‌سازی، QA، امنیت و Git منطقی‌اند؛ ابزار واقعی محیط قبل از واگذاری بررسی شود. ساخت چت جدید یا ارسال پیام نیازمند درخواست مالک است.
