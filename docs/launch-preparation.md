# آماده‌سازی شروع سریع پرامتی

تاریخ: ۲۰۲۶-۱۰-۲۳؛ برنچ محلی `finaly` از `release` در کامیت `7e17610` ساخته شد.

## تصمیم تأییدشدهٔ مالک

«حذف کارت‌های بادبزنی به عنوان کارت اصلی و برگشت به نسخهٔ کارت‌های معمولی.»

منظور اجرایی: قالب پیش‌فرض شروع سریع، کارت معمولی در چیدمان شبکه‌ای است. قالب بادبزنی همچنان به‌عنوان تمپلیت جایگزین حفظ می‌شود و مدیر می‌تواند آن را فعال کند.

## تغییر اول

- مدیریت ← برندینگ و ظاهر سایت ← قالب کارت‌های پرامپت: انتخاب تصویری بین «کارت معمولی» و «کارت بادبزنی»؛ اعمال با ذخیرهٔ برندینگ.
- انتخاب برای شش بخش صفحه اصلی و نتایج جستجو یکسان است. تنظیم ذخیره‌نشده یا نامعتبر، معمولی نمایش داده می‌شود؛ API فقط دو مقدار `grid` و `fan` را می‌پذیرد.
- ساختار شش جایگاه، فیلترها، جستجو، کپی و نشان حفظ می‌شوند. هنگام جستجو فقط بخش نتیجه دیده می‌شود.
- تنظیم قالب از همان لایهٔ settings فعلی استفاده می‌کند؛ مهاجرت PostgreSQL برای این تغییر لازم نیست.
- تغییرات محلی قبلی n8n و مستندات حفظ شده‌اند؛ فایل‌های ناتمام n8n در working tree لوکال مانده‌اند و در کامیت قالب کارت قرار نمی‌گیرند.

## اعتبارسنجی و انتشار

بررسی TypeScript، هر ۳۲ آزمون (شامل ذخیره/بازخوانی قالب، کنترل دسترسی و رد مقدار نامعتبر) و بیلد موفق بودند. API لوکال قالب معمولی را ذخیره و بازخوانی کرد؛ تنظیمات AI، لوگو و شش جایگاه حفظ شدند و محتوای PostgreSQL و API بخش‌ها در دسترس‌اند. تست ظاهری مرورگر هنوز تکمیل نشده: تب قدیمی روی صفحهٔ خطای داخلی مرورگر مانده و ابزار دسترسی به آن را رد می‌کند؛ بازکردن دوبارهٔ آدرس توسط مالک لازم است. در درخواست بعدی مالک برای دیده‌شدن برنچ در GitHub، انتشار برنچ `finaly` با کامیت همین تغییرات قالب کارت پیگیری شد. این مرحله شامل Deploy نیست.

تغییرات بعدی شروع سریع، پس از دریافت از مالک به همین سند اضافه می‌شوند.
