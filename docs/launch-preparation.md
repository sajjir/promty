# آماده‌سازی شروع سریع پرامتی

تاریخ: ۲۰۲۶-۱۰-۲۳؛ برنچ محلی `finaly` از `release` در کامیت `7e17610` ساخته شد.

## تصمیم تأییدشدهٔ مالک

«حذف کارت‌های بادبزنی به عنوان کارت اصلی و برگشت به نسخهٔ کارت‌های معمولی.»

منظور اجرایی: قالب پیش‌فرض شروع سریع، کارت معمولی در چیدمان شبکه‌ای است. قالب بادبزنی همچنان به‌عنوان تمپلیت جایگزین حفظ می‌شود و مدیر می‌تواند آن را فعال کند.

## تغییر اول

- مدیریت ← برندینگ و ظاهر سایت ← قالب کارت‌های پرامپت: انتخاب تصویری بین «کارت معمولی» و «کارت بادبزنی»؛ اعمال با ذخیرهٔ برندینگ.
- انتخاب برای شش بخش صفحه اصلی و نتایج جستجو یکسان است. تنظیم ذخیره‌نشده یا نامعتبر، معمولی نمایش داده می‌شود؛ API فقط دو مقدار `grid` و `fan` را می‌پذیرد.
- ساختار شش جایگاه، فیلترها، جستجو، کپی و نشان حفظ می‌شوند. هنگام جستجو فقط بخش نتیجه دیده می‌شود.
- تنظیم قالب از همان لایهٔ settings فعلی استفاده می‌کند؛ مهاجرت PostgreSQL برای این تغییر لازم نیست.
- تغییرات محلی قبلی n8n و مستندات حفظ شده‌اند؛ فایل‌های ناتمام n8n در working tree لوکال مانده‌اند و در کامیت قالب کارت قرار نمی‌گیرند.

## اعتبارسنجی و انتشار

بررسی TypeScript، هر ۳۲ آزمون (شامل ذخیره/بازخوانی قالب، کنترل دسترسی و رد مقدار نامعتبر) و بیلد موفق بودند. API لوکال قالب معمولی را ذخیره و بازخوانی کرد؛ تنظیمات AI، لوگو و شش جایگاه حفظ شدند و محتوای PostgreSQL و API بخش‌ها در دسترس‌اند. تست ظاهری مرورگر هنوز تکمیل نشده: تب قدیمی روی صفحهٔ خطای داخلی مرورگر مانده و ابزار دسترسی به آن را رد می‌کند؛ بازکردن دوبارهٔ آدرس توسط مالک لازم است. در درخواست بعدی مالک برای دیده‌شدن برنچ در GitHub، انتشار برنچ `finaly` با کامیت همین تغییرات قالب کارت پیگیری شد. این مرحله شامل Deploy نیست.

تغییرات بعدی شروع سریع، پس از دریافت از مالک به همین سند اضافه می‌شوند.


## هدر خلوت و منوی حساب — ۲۰۲۶-۱۰-۲۵

درخواست مالک از دو کامنت مرورگر و کد منوی پیوست: تنظیم لوگو تا ۱۳۳ پیکسل؛ انتقال داشبورد به منوی جدید کاربر؛ هدر شامل برند، حساب و همبرگر باشد.

پیاده‌سازی محلی:
- حداکثر اندازهٔ لوگو در دسکتاپ و موبایل از فرم برندینگ و اعتبارسنج مشترک API تا ۱۳۳px افزایش یافت. انتخاب ذخیره‌شده و پیش‌فرض‌ها خودکار بزرگ نشدند؛ ادمین اندازهٔ دلخواه را انتخاب می‌کند. ارتفاع هدر متناسب با لوگو و فضای منوی همبرگری متناسب با ارتفاع هدر محاسبه می‌شود.
- لینک‌های مستقل داشبورد، مدیریت و آیکن جداگانهٔ خانه از ردیف اصلی حذف شدند. داشبورد و ذخیره‌شده‌ها، پنل مدیریت (با همان کنترل نقش)، انتخاب پوسته و خروج در منوی حساب هستند. خانه و بخش‌های عمومی در همبرگر می‌مانند. مهمان همچنان ورود و انتخاب پوسته در همبرگر را دارد.
- ساختار منوی ارسالی مالک با CSS ماژولِ سازگار با توکن‌های پرامتی و متن فارسی تطبیق یافت: منوی کشویی دسکتاپ، پنل پایین موبایل، هویت حساب و نقش، حرکت نشانگر، کنترل صفحه‌کلید، بستن با بیرون/ESC و نمایش انتظار خروج. وضعیت حضور آنلاین ساختگی به حساب‌ها اضافه نشد. تغییر پوسته به ThemeProvider موجود وصل است.

اعتبارسنجی: TypeScript، بیلد فرانت‌اند/بک‌اند و سه آزمون موجود لوگو با مرز جدید موفق شدند. API لوکال اندازهٔ ۱۳۳ را برای هر دو حالت ذخیره و عیناً بازخوانی کرد؛ ۱۳۴ را رد کرد. تنظیمات پیشین لوکال پس از این آزمون بازیابی شدند. بک‌اند همین پیش‌نمایش مجدداً اجرا شد و HTTP لوکال سالم بود.

محدودیت بازبینی: ابزار مرورگر خطای `transport closed before response` داد؛ با اتصال مجدد اعلام‌شدهٔ مالک، reset و اتصال مستقیم به URL لوکال نیز بازیابی نشد. بنابراین تست تعاملی منو و بررسی ظاهری دسکتاپ/موبایل هنوز انجام نشده و موفق اعلام نمی‌شود. درخواست نمایش لوکال در پنل Codex queued برگشت، نه تأیید بازشدن صفحه. این مرحله Commit/Push/Deploy ندارد و تغییرات قبلی n8n حفظ شده‌اند.


## ثبت یکپارچهٔ تغییرات — ۲۰۲۶-۱۰-۲۵

مالک پس از تأیید ظاهر محلی، ثبت و Push تمام تغییرات فعلی روی برنچ `finaly` را صریحاً درخواست کرد. بسته شامل هدر و منوی حساب، اندازهٔ لوگو تا ۱۳۳px، آماده‌سازی وفادار خروجی n8n و مرحلهٔ بازبینی ادمین، فیلتر تصویر ورودی، فیلدهای اصلی/پیشرفته، نگهداری editorial/relatedUseCases و migration غیرمخرب آن، آرشیو نسخه‌های پیام‌ها و قالب‌های پاک‌سازی‌شدهٔ ورک‌فلو و مستندات پژوهش/استقرار است.

کنترل نهایی: TypeScript، بیلد فرانت‌اند و بک‌اند و هر ۴۱ آزمون موفق شدند. کنترل whitespace فایل‌های stage‌شده فقط یک فاصلهٔ انتهای خط در snapshot اصلی `n8n-agaent/02-design/v001-original.md:91` نشان داد؛ برای حفظ عین نسخهٔ اولیه دست‌نخورده ماند. کنترل سایر فایل‌های stage‌شده موفق بود. سه فایل آزمونِ نیازمند فرایند/سرور موقت ابتدا در محیط محدود ناموفق بودند؛ با دسترسی مناسب، همان آزمون‌ها و سپس کل مجموعه بدون تغییر کد موفق شدند. بررسی الگوهای رایج رمز/توکن در ۱۷۳ فایل تغییرکرده یا جدید موردی پیدا نکرد؛ قالب‌های JSON ورک‌فلو Credential reference ندارند. فایل‌های خصوصی و تنظیمات واقعی محیط بیرون Git می‌مانند.

این درخواست صرفاً ثبت و انتشار Git است؛ Publish ورک‌فلو، migration پایگاه مقصد یا Deploy سرور انجام نمی‌شود. وضعیت draft تستِ n8n و محدودیت بررسی ظاهری ابزار در گزارش‌های قبلی همچنان معتبر است؛ تأیید ظاهری مالک جای شاهد اجرای مرورگر توسط ابزار معرفی نمی‌شود.
