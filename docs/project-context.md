## داده
هدف تأییدشده مالک: PostgreSQL ذخیره‌ساز اصلی محتوا و حساب‌ها باشد. آخرین گزارش سرور، JSON + PM2 بوده و مهاجرت زنده هنوز انجام نشده است. JSON فایل پایدار است، نه حافظه موقت. وجود DATABASE_URL فعال، adapter PostgreSQL را انتخاب می‌کند. خطای اتصال نباید به JSON برگردد.
محدودیت معماری فعلی: settings/branding و Knowledge Graph هنوز در db.json و OTP/ابطال نشست در فایل‌های خصوصی هستند. تبدیل همه این اجزا به PostgreSQL کار جداست؛ فعال‌بودن Prisma به معنی حذف کامل JSON نیست. db.json، dl و .private را حتی بعد از مهاجرت حفظ کنید.

معرفی محصول زیر کسب‌وکار است؛ سوشال مدیا گروه مستقل دارد. learning به teaching نرمال می‌شود. نشان آزموده‌شده فقط با شواهد اجرای واقعی ابزار معتبر است.
