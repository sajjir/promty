# گام اول صفحات راهنما و اعتماد — ۲۰۲۶-۱۰-۲۶

## درخواست و محدودهٔ تأیید
مالک متن طرح صفحات /guide، /about و /contact، فوتر واقعی و بلاگ PostgreSQL را فرستاد. در پاسخ به سؤال محدوده، «فعلاً گام اول را کامل کن» را انتخاب کرد. پایهٔ کار finaly/de8f2d7 است. این مرحله فقط روی لوکال است؛ BlogPost، migration، seed، Commit/Push و تغییر سرور در آن اجرا نمی‌شوند.

## پیاده‌سازی
- منبع واحد محتوای ثابت: src/lib/trustPages.ts. عنوان، h1، توضیح، نوع Schema، بخش‌ها و لینک‌ها از همین داده خوانده می‌شوند.
- TrustPageContent کامپوننت معنایی مشترک است؛ سرور با renderToStaticMarkup و کلاینت با همان کامپوننت رندر می‌کنند. به‌جز پوستهٔ برنامه، محتوای داخل مقاله یکسان است. متن معمولی با React escape می‌شود؛ HTML خام ورودی ندارد.
- buildSeo پیش از درخواست آرشیو، مسیرهای اعتماد را تشخیص می‌دهد؛ صفحات راهنما حتی در نبود دسترسی آرشیو به repository درخواست نمی‌زنند. HTTP handler موجود server.ts همین renderer را با وضعیت ۲۰۰ و Canonical هر مسیر تحویل می‌دهد؛ مسیرهای React نیز افزوده شدند. نیازی به مسیر HTTP تکراری جدا نبود.
- BreadcrumbList و WebPage/AboutPage/ContactPage، بدون ادعای رتبه/تأیید سازمانی یا FAQPage. سه مسیر یک‌بار در sitemap قرار می‌گیرند؛ Query تبلیغاتی Canonical مسیر اصلی را حفظ می‌کند.
- راهنما: فیلترهای چندانتخابی، تصویر مرجع، فیلدگذاری، کپی و اجرای متن در ابزار مقصد و تفاوت prompt/skill/agent-guide. درباره: هدف و شناسنامهٔ محتوا بدون ادعای آزموده‌بودن همهٔ آرشیو. تماس: mailto:betavan.co@gmail.com و شبکه‌های تأییدشدهٔ اینستاگرام و تلگرام، همراه با راهنمای گزارش مشکل و پیشنهاد کاربرد.
- فوتر مستقل SiteFooter با معرفی ساده و دو ستون لینک استاندارد a/href است. ستون راهنما به سه صفحهٔ واقعی می‌رود. ستون آرشیو علاوه بر خانه، تا سه کاربرد و دو ابزار دارای محتوای منتشرشده را از /api/facets می‌گیرد؛ گزینهٔ صفر/نامعتبر وارد نمی‌شود. خطای دریافت فقط لینک خانه را باقی می‌گذارد و لینک ساختگی تولید نمی‌شود. به‌زودی و آیتم غیرفعال از فوتر حذف شدند؛ هدر و موارد آیندهٔ آن در این درخواست تغییر نکردند.
- در مرورگر آشکار شد fetch تنظیمات برندینگ عنوان اختصاصی را بازنویسی می‌کند. دو انتساب document.title در AuthContext حذف شدند؛ عنوان اکنون از SeoHeadSync می‌آید و state نام برند همچنان به‌روز می‌شود. پس از رفرش و بارگذاری تنظیمات، عنوان guide/about/contact درست باقی ماند.

## شواهد
چهار آزمون جدید tests/trust-pages.test.ts: برابری محتوای React و HTML اولیه/متادیتا با repository قطع، sitemap بدون محتوای آرشیو، لینک‌های فوتر بدون placeholder و مسیرهای نامعتبر، و HTTP واقعی سه مسیر و /api/seo در fixture موقت. fixture آزمون جداست؛ دادهٔ لوکال PostgreSQL تغییر نکرد.
کل ۵۶ آزمون پروژه و TypeScript و Build موفق شدند؛ هشدار اندازهٔ باندل Vite همچنان باقی است. API فقط در پیش‌نمایش محلی به‌روز شد، با حفظ PostgreSQL، settings و کلید نشست قبلی.
در مرورگر: راهنما در دسکتاپ، تماس در عرض ۳۹۳ و ۳۲۰، و درباره بررسی شدند؛ سرریز افقی مشاهده نشد. عنوان و Canonical و AboutPage/BreadcrumbList در DOM نهایی کنترل شدند. لینک تماس از فوتر و لینک کاربرد واقعی فوتر به صفحهٔ آرشیو باز شدند؛ مقصد mailto ایمیل نیز بررسی شد، ولی باز یا ارسال نشد. هیچ ایمیل یا پیامی ارسال نشد. نشست مدیر سیستم حفظ شد.
